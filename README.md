## Overview

This repository tracks the 30-day technical upskilling program issued by Scalyn OPC management. The program focuses on six technical domains with a prescribed structure: concept review, practical exercises, AI review, and development logging.

## Constraints

- **Time allocation:** Max 1 hr/workday, 5 hrs/week company-funded (logged as "Technical Development / Upskilling")
- **Workday structure:** 0–10 min concept review · 10–45 min practical exercise · 45–55 min AI review · 55–60 min dev log
- **Core principle:** Training supports delivery, not the inverse

## Technical Domains

1. **JavaScript** - Foundations and modern practices
2. **Laravel** - PHP web framework and core concepts
3. **APIs** - Design, development, and integration
4. **Database/ORM** - Relational databases and ORM patterns
5. **Testing** - Unit and feature testing
6. **Modern App Development** - Best practices and patterns

## Reassessment Timeline

- **Week 1–2:** JavaScript + Laravel foundations, broken-code debugging exercises
- **Week 3–4:** Mini app project (concept to be approved by management)
- **Week 4 end:** Technical defence (unprepared)

## AI Workflow

The prescribed workflow is:
1. AI explains concept
2. You implement solution
3. AI reviews your work
4. You correct/refine
5. You document your learning

**Key principle:** Never treat AI output as correct without validation. Keep prompt and evidence logs.

## Getting Started

1. Create a daily development log entry in `01-development-logs/`
2. Work through exercises in the relevant domain folder under `02-exercise-solutions/`
3. Track prompts and evidence in `04-logs/`
4. Document your learning and challenge points in development logs
