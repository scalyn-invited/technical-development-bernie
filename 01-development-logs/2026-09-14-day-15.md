## Built

Vue 3 Composition API and Vue Router on the existing Laravel/Vite pipeline.
Modern ivory/forest-green login screen and protected overview, responsive layout,
labelled inputs, visible focus, busy/error states and reduced-motion support.
The overview displays the authenticated account from /api/me.

Central authentication client: login, bearer headers, sessionStorage persistence,
identity restoration on refresh, protected route guard, logout, and 401 redirect.
Wrong credentials stay a form error; timeout/network/validation errors are visible.

## Token-storage decision

For this small token-based demo, sessionStorage keeps the session through refresh
within the tab. It remains JavaScript-readable and therefore vulnerable to XSS.
Closing the tab does not revoke the server token. Production first-party use should
move to Sanctum HttpOnly session cookies and CSRF protection. Storage failure falls
back to memory and warns that refresh will sign out.
