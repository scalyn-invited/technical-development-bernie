# Development Logs

Daily learning notes and reflections on your technical upskilling journey.

## Format

Each day's log should include:

- **Date:** YYYY-MM-DD
- **Session Duration:** Time spent on this day's training
- **Topics Covered:** What you studied/practiced
- **Key Learnings:** Main takeaways
- **Challenges:** What was difficult or unclear
- **Next Steps:** What you'll focus on next

## Naming Convention

Use ISO date format: `2026-08-24-log.md`, `2026-08-25-log.md`, etc.

## Example

```markdown
# Development Log - 2026-08-24

**Session Duration:** 60 min  
**Topics:** JavaScript fundamentals - callbacks vs promises  

## What I Learned
- Callbacks are functions passed as arguments
- Promises provide better error handling and chaining
- async/await is syntactic sugar over promises

## Challenges
- Understanding promise rejection and error propagation
- When to use .catch() vs try/catch with async/await

## Next Steps
- Practice promise chains with real API calls
- Review async/await error handling patterns
```

---

**Purpose:** Build a reflective record of your learning, identify patterns in what works, and track progress toward the 85% target.
