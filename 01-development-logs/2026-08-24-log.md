Here's the explanation:

Map, Filter, and Reduce: What Each Does

map transforms every element in an array using a function, returning a new array of the same length. Use it when: you need a new value for each input.

const orders = [{total: 100}, {total: 200}];
const totals = orders.map(o => o.total);  // [100, 200]

filter returns a new array containing only elements where the callback returns truthy. Use it when: you need a subset of the array.

const completed = orders.filter(o => o.status === 'completed');

reduce accumulates a single value by applying a function to each element and an accumulator. Use it when: you need to combine all elements into one value (sum, object, grouped result).

const total = orders.reduce((sum, o) => sum + o.total, 0);
When Reduce is the Wrong Choice

If your goal is to transform (all elements) → use map.
If your goal is to filter (some elements) → use filter.
If your goal is to group or count (one result) → reduce is right, but a for loop or Object.groupBy() might be clearer.

Two Common Mistakes
Missing the initial value. reduce((sum, o) => sum + o.total) with no second argument fails when you try sum + o.total on the first iteration — sum is the first order object, not a number. Always provide an initial value.
Mutating the accumulator. Developers often do acc.push(item) inside reduce, which mutates the accumulator. This works but breaks immutability and can hide bugs. Build a new array or object instead:
// Wrong: mutation
reduce((acc, item) => { acc.push(item.name); return acc; }, [])

// Right: new array
reduce((acc, item) => [...acc, item.name], [])
