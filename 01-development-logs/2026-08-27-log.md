## What I Learned

1. **Foreign Key Strategy** — `restrictOnDelete` protects historical data; forces explicit application-level handling vs. silent cascades
2. **Factory Relationships** — Factories can call other factories; `Team::factory()->has(Player::factory()->count(15))` wires relationships
3. **Model Naming Edge Cases** — `Match` is a PHP 8+ reserved keyword; renamed to `MatchGame`
4. **Foreign Key Naming Conventions** — Must explicitly specify key name when multiple relationships to same model (e.g., `home_team_id` vs. `away_team_id`)
5. **Seeding Logic** — Collection methods like `->where()` followed by `->random()` enforce business rules in seed data

---

## Mistakes Made / Got Wrong

1. **Initially named model `Match`** — Didn't know `match` is a reserved keyword in PHP 8. Parser threw "unexpected token ::" error. Fixed by renaming to `MatchGame`
2. **Factory file name mismatch** — Created `MatchFactory.php` when model was `MatchGame`; Laravel's factory auto-discovery expects names to match. Renamed to `MatchGameFactory.php`
3. **Old class references in Team model** — Relationship methods referenced old `MatchModel::class` name; had to update to `MatchGame::class`
4. **Indentation inconsistency** — Players table migration had misaligned braces (cosmetic but sloppy)
