## What I Learned

1. **Resource Controllers** — One line `Route::resource()` generates 7 standardized routes with correct HTTP verbs
2. **Implicit Route Model Binding** — Type hint the model in the method signature; Laravel auto-fetches and injects
3. **Request Lifecycle** — Request → Kernel → Routing → Middleware → Model Binding → Controller → Response
4. **Route Ordering** — Specific routes MUST come before dynamic `{param}` routes or they're never matched
5. **Middleware Placement** — Can be global or route-specific; affects which routes enforce the check
6. **Debugging with Tools** — `route:list`, browser testing, cURL, and logs reveal bugs faster than reading code

---

## Mistakes Made / Got Wrong

1. **Route ordering initially confused** — Thought the order didn't matter until I tested and saw `/posts/create` matching `{post}`
2. **Middleware in group vs. individual** — Placed globally when task wanted route-specific; both work but scope matters
3. **Parameter name vs. type hint** — Initially thought `string $id` would work; doesn't match the binding
