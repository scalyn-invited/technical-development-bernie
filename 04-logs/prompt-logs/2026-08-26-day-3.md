**Key concepts explained:**
1. **Resource Controllers** — Convention for 7 REST routes; saves repetitive routing
2. **Implicit Route Model Binding** — Type-hint the model; Laravel auto-fetches and injects
3. **Request Lifecycle** — Request → Kernel → Routing → Route Matching → Middleware → Model Binding → Controller → Response
4. **Custom Middleware** — Intercepts requests before controller; can reject with custom responses
5. **Route Ordering** — Specific routes must come before dynamic `{param}` routes

**Common mistakes highlighted:**
- Forgetting to type-hint the model; using manual `findOrFail()` instead
- Placing dynamic routes before specific routes; dynamic routes match everything
- Registering middleware globally when you only need it on specific routes
