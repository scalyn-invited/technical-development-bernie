## Architecture / coverage
- **Authentication:** guest requests to protected routes return 401 with the standard error envelope
- **Authorisation (Policy-based):** owner-only access on `show`/`update`/`destroy`; approver role bypasses ownership check; enforced via `OrderPolicy`, verified at both the HTTP layer (feature tests) and in isolation (unit test, no database)
- **Validation:** required fields, `exists` rule on `customer_id`, `min:0.01` on `total`, enum-style `status` validation — each tested independently, not only bundled
- **Mass-assignment protection:** explicit test sends attacker-supplied `user_id` in the create payload and asserts the resulting record is owned by the authenticated user, not the spoofed one (`assertDatabaseHas` + `assertDatabaseMissing` pair)
- **Response shape:** `assertJsonStructure` on both `index` (data/meta/links) and `show` (data) — caught a real `array_merge_recursive` key-collision bug in the paginated collection's `meta` block
- **N+1 regression guard:** differential query-count test — asserts query count for `index` is identical at 3 records and at 10 records, rather than asserting a fixed absolute number
