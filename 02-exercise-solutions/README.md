# Exercise Solutions

Solutions to exercises assigned during the 30-day technical development program, organized by domain.

## Domains

- **javascript/** - JavaScript exercises (callbacks, promises, async/await, ES6+, etc.)
- **laravel/** - Laravel framework exercises (routing, controllers, Eloquent, middleware, etc.)
- **apis/** - API design and development exercises
- **database-orm/** - Database and ORM exercises (SQL, Eloquent patterns, migrations, etc.)
- **testing/** - Unit and feature testing exercises
- **modern-app-dev/** - Full-stack application development practices

## Exercise Format

Each exercise should include:

1. **Exercise Name/Number** - Clear identifier
2. **Acceptance Criteria** - What "done" looks like
3. **Solution Code** - Your implementation
4. **Testing** - How you validated your solution
5. **Notes** - Key insights or difficulties

## Naming Convention

Use descriptive names: `week1-js-callbacks.md`, `week1-js-promises.js`, etc.

## AI-Assisted Learning

When working with AI on exercises:
- Document the initial prompt you used
- Show the AI's suggested approach
- Record your implementation
- Log any corrections or refinements
- Save evidence in `04-logs/prompt-logs/`

---

**Key Principle:** Validate every solution; don't assume AI output is correct without testing and review.
